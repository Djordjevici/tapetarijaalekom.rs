# Tapetarija Alekom — coming soon

Serbian “Uskoro” page for [tapetarijaalekom.rs](https://tapetarijaalekom.rs).

## Open locally

```bash
cd landing-page
open index.html
# or: python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Files

- `index.html` — page structure and Serbian copy
- `styles.css` — palette, layout, motion
- `script.js` — entrance readiness + year
